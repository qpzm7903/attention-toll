# Attention Toll

Chrome 插件：监控分心网站的注意力消耗，用递增摩擦让「继续娱乐」成为有代价的显式选择。技术栈：WXT + TypeScript + Vue 3（Manifest V3）。常用命令：`npm run dev` / `npm run build` / `npm run compile`（类型检查）。
